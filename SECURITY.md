# Security Policy

## Supported versions

Rapidash is in **early development**. No stable version or security support window has been established.

## Reporting vulnerabilities

Please **do not open a public issue with exploit details, credentials, or private information**.

Use GitHub's **Private Vulnerability Reporting** feature if it is enabled for this repository: **Security → Advisories → Report a vulnerability**.

If this option is unavailable, check the maintainer's GitHub profile for a private contact method. Maintainers should configure a dedicated reporting route before public launch.

## Sensitive functionality

Because Rapidash may interact with processes, browser sessions, caches, and system resources, reports involving privilege escalation, command execution, unsafe process controls, access to user data, or data loss should be treated as potentially security-sensitive.

Please include the smallest safe reproduction, relevant versions, and affected platforms without posting secrets.
