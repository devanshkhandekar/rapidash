# Branding and Screenshot Checklist

No images are required for the repository to be public. A few **real, privacy-safe screenshots** are highly recommended before sharing it widely.

## Recommended first assets

| Asset | Suggested file | Guidance |
| --- | --- | --- |
| Main app screenshot | `assets/screenshots/overview.png` | Actual running application showing its overview or App Groups view. |
| Process Explorer screenshot | `assets/screenshots/process-explorer.png` | Show sorting/filtering and resource information; blur private process arguments and user paths. |
| Browser screenshot | `assets/screenshots/chrome-tabs.png` | Use dummy test tabs; do not expose browsing history, private titles, or account sessions. |
| Dark mode screenshot | `assets/screenshots/dark-mode.png` | Optional if it shows a meaningful visual difference. |
| Original app icon | `assets/branding/rapidash-icon.png` | Recommended 512×512 px with transparent background; prepare SVG source too. |
| GitHub social preview | `assets/branding/social-preview.png` | Optional 1280×640 px branded card with simple app screenshot and project tagline. |
| Short demo clip | `assets/demo.gif` | Optional; 8–15 seconds, optimized for file size. |

Once an actual screenshot is present, remove the surrounding HTML comments from the corresponding `README.md` image link.

## Important rights and privacy checklist

- Use **original** branding. Rapidash is also a Pokémon species name; do not reuse Pokémon sprites, screenshots, character silhouettes, or other protected material.
- Do not include watermarked or unlicensed images or fonts.
- Prefer a distinctive, original flame/horse-inspired symbol **without imitating the Pokémon character's distinctive appearance**; consider renaming for a durable brand.
- Remove real hostnames, OS usernames, file paths, personal documents, and Chrome tab titles from screenshots.
- Screenshots must represent current functionality; avoid fabricated feature states.
- Record asset authorship/license if a third-party asset is used.
